# Dataset Register — Public Bootstrap Sources

This mirrors the PRD's Appendix B table, replaced with actual verified
findings instead of the PRD's placeholder "Verify..." entries. Round 1
(2026-09-14) covered the five candidate sources named in PRD §13 /
Appendix B. Round 2 (2026-09-14, same day, separate pass) independently
re-verified a set of corrections and new sources the product owner
surfaced from their own research — every claim below was checked against
a live source (HF API, Dataverse API, GitHub API, or a reachable site),
not taken on trust, exactly like round 1. All sources are checked against
the PRD §13.6 ingestion rule (license → provenance → sampling/quality →
bias/context → duplication → PII → Afribit approval).

**Everything imported from this register is `status='draft'` in
`language_entries`. Nothing here is Afribit-approved language data** — see
PRD §25.1 and ADR 0005. Import scripts live in [`db/seed/`](../db/seed);
see [`db/seed/README.md`](../db/seed/README.md) to run them.

The **Corpus Layer** column below uses the model defined in
[`docs/LANGUAGE_CORPUS.md`](LANGUAGE_CORPUS.md) (`L0_reference` /
`L1_licensed_external` / `L2_community_collected` / `L3_afribit_reviewed`
/ `L4_gold`). "N/A" means nothing was imported, so no layer applies.

Checked 2026-09-14 (round 1) and 2026-09-14 (round 2, product-owner
recheck).

## Summary

- **Imported (round 1):** LughaKonnect — 40 rows, `L1_licensed_external`, `status='draft'`, `source_context='public_dataset:lughakonnect'`. See [`db/seed/001_lughakonnect_sheng.sql`](../db/seed/001_lughakonnect_sheng.sql).
- **Imported (round 2):** KenCorpus — 28 rows, `L0_reference`, `status='draft'`, `source_context='public_dataset:kencorpus'`. Verified via a live SQL count (`language_entries` 40→68, idempotent re-run confirmed 68→68). See [`db/seed/002_kencorpus_text.sql`](../db/seed/002_kencorpus_text.sql).
- **Total external verified seeds so far: 68 rows** across 2 sources (was 40 after round 1).
- **Confirmed correct and left skipped:** LughaGen (still gated, still disclosed-synthetic Sheng), the PRD's original "Kenyan Conversational Dataset" (no real source matches the name).
- **Recheck reversed a round-1 finding:** KenCorpus — round 1 said unreachable; round 2 found it fully reachable via Hugging Face and Harvard Dataverse and imported a verified sample.
- **Recheck confirmed a round-1 finding unchanged:** Sheng Doctor (`cokoyoh/sheng-dictionary`) — the product owner's claim of new CSV files in this exact repo is **false**; the repo is byte-for-byte the same Laravel skeleton with no data, per a full recursive GitHub tree listing.
- **Could not verify at all:** the "Liva" Swahili-English conversational corpus — extensive search (HF, GitHub, web) found no matching dataset under this name. Flagged as unconfirmed rather than imported or fabricated; needs a real URL/id from whoever originally identified it.
- **Verified and quarantined (register-only, deliberately NOT imported):** `EgesaWO/Sheng_sml` (1,042 rows, scraped Bible-verse translations, no rights chain), `EgesaWO/Eng2sheng` (4,050 rows, same underlying content, no documentation), `micymike/kenyan-conversational-data` (15,552 declared rows, ~96% of which are empty on inspection — worse than "thin provenance"), Silencio `SilencioNetwork/swahili-speech` (103 human-transcribed speakers, genuinely CC BY-NC 4.0 — license-incompatible regardless of quality).
- Rationale throughout favors **verifying over trusting, and skipping over fabricating**: every claim in this register — the product owner's included — was checked against a live, independently reachable source before being written down as fact.
