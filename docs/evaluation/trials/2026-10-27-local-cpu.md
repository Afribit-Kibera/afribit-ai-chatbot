# First real local CPU inference trial

**Date:** 27 October 2026, Africa/Nairobi. **Decision:** execution works; hold this model from learner use.
No rented compute, paid inference API, production deployment or real learner data. Electricity,
connectivity and local storage costs were not measured.

not TEE attestation or protection from the laptop administrator.

## Protocol and measured execution

Four internal synthetic questions, one model, bare/full-product-plus-supplied-context variants, one
sequential repetition; temperature 0, 90-word instruction, 160 output tokens, 120-second attempt bound.
The product prompt contains language/safety guidance and examples, so differences are not solely RAG.
No application DB, actual retrieval selection, account memory or product safety post-filter ran here.

| Observation | Result |
|---|---:|
| Completed generation requests | 8 of 8 |
| Transport failures/skips | 0 / 0 |
| Time to first content | 0.45–28.06 s |
| Full-attempt time | 2.01–36.09 s |
| Windows peak process working set | 1,593,630,720 bytes, about 1.48 GiB |
| Answers reaching output ceiling | 4 of 8 |
| Paid model API / rental charges | USD 0 |

The process-memory metric is not GPU VRAM or the entire machine's memory requirement. The same process
served every case; cache warmth and other laptop work were not controlled. Artifact tests ran during
part of the session. These eight samples establish neither a meaningful p95 nor concurrency capacity.
Authentication/health requests are not counted as successful generation calls.

## Quality findings — no learner release

AI inspection found obvious problems worth recording before another experiment:

- Bare Sheng and Kiswahili answers repeated the prompt or unrelated wording.
- The supplied-context recovery-phrase answer failed to deliver the required clear advice against
  sharing recovery words, despite having the safety passage available.
- Without context, the fictional community-desk answer invented a date/time and a USD 10 fee.
- With the supplied passage, the desk answer correctly gave Tuesday 14:00–16:00 and free sessions,
  but appended an irrelevant follow-up copied in style from the wider prompt.
- Unknown-trainer questions received an invented name or repetition instead of a clear admission that
  no name was available. Four answers also reached the configured token ceiling.

There is no human quality score, validated safety rate or overall model winner. Technical completion
must not be quoted as eight correct answers. Keep this exact checkpoint/recipe evaluation-only. The
next comparison should test a stronger instruction model and a shorter prompt before considering
fine-tuning. Reviewed-card answers remain a useful model-free control; shared training still requires
separate consent and held-out evaluation.

## Failed and corrective checks retained

The initial typecheck caught a duplicate `artifacts` summary property; it was corrected. The first
archive fixture suite [49f5ef4c](../../../output/trials/49f5ef4c-3eb0-4bbe-9173-bcf1022d3146.json) failed
after four checks because its fixture creator omitted the .NET compression assembly. Subsequent suites
passed five checks. Archive validation was strengthened to terminate on unsafe paths and refuse parent
paths, alternate data streams and symlink entries before extraction. The latest
[artifact proof](../../../output/proof/p4-artifact-verification-proof.json) links the retained suite.

A cached verification attempt [f08980fa](../../../output/trials/f08980fa-722b-4fd4-9759-2c481c0ddd74.json)
was refused with about 2.17 GB free RAM while build/tests were active. The initial memory guard applied
to verification too broadly; it now applies to generation, and is checked again after acquisition.
The refusal was retained, not rewritten as success. Later cached verification
[158cd97d](../../../output/trials/158cd97d-a919-4fb2-bb57-2b76c7752085.json) passed: hashes rechecked,
archive extracted under the hardened guard, runtime help checked, zero transferred bytes/model calls.
An intermediate cached record used `downloadedBytes` for combined artifact size; new records separate
`artifactBytes` from actual `transferredBytes`. Do not interpret that legacy field as another transfer.

Full test suite, typecheck and build passed; final cached verification and API typecheck also passed
after the reporting/resource-guard refinements. No production model switch, GPU benchmark, physical
Mesh test, foreign-provider privacy claim or training result follows from this trial.
