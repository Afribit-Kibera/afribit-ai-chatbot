# Green education entry and Open Notebook: implementation trials

6 November 2026. First local implementation of F-034, authorized by Edmund's green/Open Notebook
learner-flow request. This is engineering evidence, not a completed learner study or public service.
The machine's existing application database, Proxmox host and router configuration were not changed.

## Result and scope

The learner path is intro → three-step setup → focus choice → Education → Bitcoin101 or personal
source notebooks. Work/Development remain deferred. Green SVG motion and an optional regenerated
intro replace the purple direction. The original attached references and first video remain archived.
The learner interface is separate from the planned AI Studio; this pass does not redesign staff tools.

Open Notebook is a real source engine behind Afribit's authenticated API. Notebook ownership and
community membership are enforced before upstream access. Text imports, source reads and exclusive
source deletion were exercised against the pinned Docker image. Inference in this integration proof
is a synthetic processor fixture. **No real model comprehension, citation accuracy, Sheng quality or
learning outcome was measured.** The browser fixture proof is separately labeled and does not stand
in for the live source-engine proof.

## Privacy and source limits

Private notebooks are account/community scoped and stay local-only through Afribit's gateway,
including resumed requests that omit the notebook ID. Their contents do not automatically enter
community knowledge, training data or hosted embeddings. Imports disable transformations, embeddings
and background processing. A local inference service still needs to be configured before genuine
notebook answers are available; unavailable processing must remain labeled unavailable.

This build is **server-side access control**, not passkey authentication, an encrypted phone vault or
protection from a privileged box administrator. The operator can access plaintext. Browser dictation
is separately disclosed and disabled for local-only processing; private/local speech is pending.
Source retrieval selects bounded lexical windows from at most six text sources. PDF/OCR, arbitrary
URL fetching, large-book semantic retrieval and verified citations are not implemented here.
Account erasure refuses while notebooks remain, avoiding orphaned upstream text; notebook deletion
also requests deletion of exclusive source text. Chat copies and backups have separate lifecycles.

## Runtime and handoff

Docker images are pinned in the [source-engine guide](../../guides/open-notebook-source-engine.md).
No model weights were downloaded. Afribit SQL used fresh PGlite; the configured application database
was not migrated. The browser development preview and proof containers are temporary verification
processes, not a pilot deployment. Cleanup state is recorded in the implementation journal and local
verification summary. Volumes and unrelated Docker services are preserved.
